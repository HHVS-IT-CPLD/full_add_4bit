## 概述

這個專案使用 Verilog 語言設計了一個4位元全加器電路。該設計可以執行兩個4位元無符號整數的加法運算，並產生4位元的和以及進位輸出。全加器是數位電路設計中的基礎構建模塊，廣泛應用於算術邏輯單元 (ALU)、計數器、累加器等電路中。

### 設計特點
- **簡潔性**: 採用行波進位結構，易於理解和實現
- **實用性**: 適合小位寬應用 (≤16位)
- **可擴展性**: 可輕鬆級聯構建更寬的加法器
- **教育性**: 完整的註解和說明，適合嵌入式系統和邏輯設計教學

## 模組詳解

### 1. full_adder_1bit 模組

#### 功能說明
1位元全加器是數位邏輯電路設計中的核心構件。它接受三個1位輸入 (a、b、cin)，經過邏輯運算，產生1位的和 (sum) 和進位 (cout)。

#### 埠 (Port) 定義

| 埠名稱 | 方向 | 寬度 | 描述 |
|--------|------|------|------|
| a | input | 1bit | 第一個輸入位元 (被加數) |
| b | input | 1bit | 第二個輸入位元 (加數) |
| cin | input | 1bit | 進位輸入 (來自前一級) |
| sum | output | 1bit | 和輸出 (當前位的計算結果) |
| cout | output | 1bit | 進位輸出 (送往下一級) |

#### 電路實現
```
       ┌─────────────────────┐
   a ──┤                     │
       │   XOR XOR (和)      ├── sum
   b ──┤                     │
       │  (A XOR B XOR Cin)  │
  cin─┤                     │
       └─────────────────────┘

       ┌─────────────────────┐
   a ──┤                     │
       │  AND & OR (進位)    ├── cout
   b ──┤                     │
       │ (A·B)+(B·Cin)+(A·Cin)│
  cin─┤                     │
       └─────────────────────┘
```

#### 邏輯方程
- **Sum** = a ⊕ b ⊕ cin   (三輸入異或)
- **Cout** = (a · b) + (b · cin) + (a · cin)   (多數採樣)

### 2. full_adder_4bit 模組

#### 功能說明
4位元全加器透過將4個1位全加器進行級聯連接，實現兩個4位元數字的加法運算。這種結構稱為「行波進位加法器 (Ripple Carry Adder)」。

#### 埠 (Port) 定義

| 埠名稱 | 方向 | 寬度 | 描述 |
|--------|------|------|------|
| A | input | 4bit | 第一個4位元輸入 (被加數) |
| B | input | 4bit | 第二個4位元輸入 (加數) |
| Cin | input | 1bit | 進位輸入 |
| Sum | output | 4bit | 4位元和輸出 (加法結果) |
| Cout | output | 1bit | 進位輸出 (溢位標誌) |

#### 內部結構
```
carry[0] = Cin                                (外部進位注入)
carry[1] = FA0的輸出 (cout)                   (第0級到第1級)
carry[2] = FA1的輸出 (cout)                   (第1級到第2級)
carry[3] = FA2的輸出 (cout)                   (第2級到第3級)
Cout = FA3的輸出 (cout)                       (最終進位)
```

## 邏輯設計

### 1. 真值表 (1位全加器)

| a | b | cin | sum | cout | 說明 |
|---|---|-----|-----|------|------|
| 0 | 0 |  0  |  0  |  0   | 0+0+0=0，無進位 |
| 0 | 0 |  1  |  1  |  0   | 0+0+1=1，無進位 |
| 0 | 1 |  0  |  1  |  0   | 0+1+0=1，無進位 |
| 0 | 1 |  1  |  0  |  1   | 0+1+1=2，產生進位 |
| 1 | 0 |  0  |  1  |  0   | 1+0+0=1，無進位 |
| 1 | 0 |  1  |  0  |  1   | 1+0+1=2，產生進位 |
| 1 | 1 |  0  |  0  |  1   | 1+1+0=2，產生進位 |
| 1 | 1 |  1  |  1  |  1   | 1+1+1=3，產生進位 |

**規律總結:**
- **Sum** = 1 的情況: 輸入中有奇數個1
- **Cout** = 1 的情況: 輸入中有兩個或以上的1

### 2. 邏輯方程推導

#### Sum的推導 (異或運算)
```
Sum = a'·b'·cin + a'·b·cin' + a·b'·cin' + a·b·cin
    = (a'·b' + a·b)·cin' + (a'·b + a·b')·cin
    = (a⊕b)'·cin' + (a⊕b)·cin
    = a⊕b⊕cin
```
**結論**: Sum是三個輸入的異或結果

#### Cout的推導 (進位邏輯)
```
Cout = a'·b·cin + a·b'·cin + a·b·cin' + a·b·cin
     = cin(a'·b + a·b') + a·b(cin' + cin)
     = cin(a⊕b) + a·b
     = a·b + cin(a⊕b)
     或等價於
     = a·b + b·cin + a·cin
```
**結論**: Cout在至少兩個輸入為1時產生進位

### 3. Verilog 實現

```verilog
// 1位全加器邏輯
assign sum  = a ^ b ^ cin;
assign cout = (a & b) | (b & cin) | (a & cin);

// 4位全加器進位級聯
assign carry[0] = Cin;
// FA0輸出的進位 → carry[1] → FA1的輸入
// FA1輸出的進位 → carry[2] → FA2的輸入
// FA2輸出的進位 → carry[3] → FA3的輸入
// FA3輸出的進位 → Cout (最終進位)
```

## 工作原理

### 加法過程步驟

#### 步驟1: 初始化進位
```
carry[0] ← Cin (一般為0，除非需要加1)
```

#### 步驟2: 計算第0級
```
Sum[0]  = A[0] XOR B[0] XOR carry[0]
carry[1] = (A[0] AND B[0]) OR (B[0] AND carry[0]) OR (A[0] AND carry[0])
```

#### 步驟3: 計算第1級
```
Sum[1]  = A[1] XOR B[1] XOR carry[1]
carry[2] = (A[1] AND B[1]) OR (B[1] AND carry[1]) OR (A[1] AND carry[1])
```

#### 步驟4: 計算第2級
```
Sum[2]  = A[2] XOR B[2] XOR carry[2]
carry[3] = (A[2] AND B[2]) OR (B[2] AND carry[2]) OR (A[2] AND carry[2])
```

#### 步驟5: 計算第3級
```
Sum[3] = A[3] XOR B[3] XOR carry[3]
Cout   = (A[3] AND B[3]) OR (B[3] AND carry[3]) OR (A[3] AND carry[3])
```

### 進位傳播路徑

```
Cin (外部進位)
 ↓
+────────────────────────────────────────────────────────+
│                                                        │
│  ┌─────────────────────────────────────────────┐     │
│  │         進位級聯鏈 (Carry Chain)             │     │
│  └─────────────────────────────────────────────┘     │
│                                                        │
│  第0級: 計算最低位 (LSB)                               │
│  → carry[1]                                           │
│     ↓                                                  │
│  第1級: carry[1] 作為輸入                              │
│  → carry[2]                                           │
│     ↓                                                  │
│  第2級: carry[2] 作為輸入                              │
│  → carry[3]                                           │
│     ↓                                                  │
│  第3級: carry[3] 作為輸入 (計算最高位 MSB)            │
│  → Cout (最終進位輸出)                                │
│                                                        │
+────────────────────────────────────────────────────────+
```

**重點**: 進位必須逐級傳播，這是行波進位加法器的特點

## 使用範例

### 範例1: 基本加法 (3 + 5 = 8)
```
輸入:
  A    = 4'b0011  (十進制: 3)
  B    = 4'b0101  (十進制: 5)
  Cin  = 1'b0

計算過程:
  第0級: 1 + 1 = 10 (二進制) → Sum[0]=0, carry[1]=1
  第1級: 1 + 0 + 1(進位) = 10 → Sum[1]=0, carry[2]=1
  第2級: 0 + 1 + 1(進位) = 10 → Sum[2]=0, carry[3]=1
  第3級: 0 + 0 + 1(進位) = 1 → Sum[3]=1, Cout=0

輸出:
  Sum  = 4'b1000  (十進制: 8)
  Cout = 1'b0
```

### 範例2: 進位溢位 (15 + 1 = 16)
```
輸入:
  A    = 4'b1111  (十進制: 15)
  B    = 4'b0001  (十進制: 1)
  Cin  = 1'b0

計算過程:
  第0級: 1 + 1 = 10 (二進制) → Sum[0]=0, carry[1]=1
  第1級: 1 + 0 + 1(進位) = 10 → Sum[1]=0, carry[2]=1
  第2級: 1 + 0 + 1(進位) = 10 → Sum[2]=0, carry[3]=1
  第3級: 1 + 0 + 1(進位) = 10 → Sum[3]=0, Cout=1

輸出:
  Sum  = 4'b0000  (十進制: 0)
  Cout = 1'b1  ← 溢位標誌，表示結果超過15

實際結果: (Cout & Sum) = 5'b10000 = 16
```

### 範例3: 帶進位輸入 (3 + 2 + 1(進位) = 6)
```
輸入:
  A    = 4'b0011  (十進制: 3)
  B    = 4'b0010  (十進制: 2)
  Cin  = 1'b1     ← 外部進位輸入

計算過程:
  第0級: 1 + 0 + 1(Cin) = 10 → Sum[0]=0, carry[1]=1
  第1級: 1 + 1 + 1(進位) = 11 → Sum[1]=1, carry[2]=1
  第2級: 0 + 0 + 1(進位) = 1 → Sum[2]=1, carry[3]=0
  第3級: 0 + 0 + 0(進位) = 0 → Sum[3]=0, Cout=0

輸出:
  Sum  = 4'b0110  (十進制: 6)
  Cout = 1'b0
```

### 範例4: 最大值相加 (15 + 15 = 30)
```
輸入:
  A    = 4'b1111  (十進制: 15)
  B    = 4'b1111  (十進制: 15)
  Cin  = 1'b0

計算過程:
  第0級: 1 + 1 = 10 → Sum[0]=0, carry[1]=1
  第1級: 1 + 1 + 1 = 11 → Sum[1]=1, carry[2]=1
  第2級: 1 + 1 + 1 = 11 → Sum[2]=1, carry[3]=1
  第3級: 1 + 1 + 1 = 11 → Sum[3]=1, Cout=1

輸出:
  Sum  = 4'b1110  (十進制: 14)
  Cout = 1'b1

實際結果: (Cout & Sum) = 5'b11110 = 30
```

## 訊號說明

### 2. 4位全加器的訊號定義

#### 輸入訊號 (Input Signals)

| 訊號 | 寬度 | 預設值 | 說明 |
|------|------|--------|------|
| A[3:0] | 4bit | - | 被加數 (第一個加數)<br>A[0] = LSB (最低有效位)<br>A[3] = MSB (最高有效位) |
| B[3:0] | 4bit | - | 加數 (第二個加數)<br>B[0] = LSB (最低有效位)<br>B[3] = MSB (最高有效位) |
| Cin | 1bit | 0 | 進位輸入 (主要用於級聯或加1操作)<br>Cin=0: 正常加法<br>Cin=1: 結果自動加1 |

#### 輸出訊號 (Output Signals)

| 訊號 | 寬度 | 說明 |
|------|------|------|
| Sum[3:0] | 4bit | 和輸出 (加法的低4位結果)<br>Sum[0] = LSB<br>Sum[3] = MSB |
| Cout | 1bit | 進位輸出 (溢位標誌)<br>Cout=0: 結果在4位內<br>Cout=1: 結果超過15，需要5位表示 |

#### 內部訊號 (Internal Signals)

| 訊號 | 寬度 | 說明 |
|------|------|------|
| carry[3:0] | 4bit | 進位級聯信號<br>carry[0] = 外部進位 Cin<br>carry[1] = FA0輸出進位<br>carry[2] = FA1輸出進位<br>carry[3] = FA2輸出進位 |

### 加法的完整結果表示

當需要完整的5位結果 (無損信息) 時:
```
完整結果 (5位) = {Cout, Sum[3:0]}

範例:
  15 + 15 = ?
  Sum = 4'b1110, Cout = 1'b1
  完整結果 = 5'b11110 = 30
```

## 時序特性

### 1. 延遲分析

#### 邏輯延遲組成
```
輸入至輸出的延遲 = 進位傳播延遲 + 最後級XOR延遲
```

#### 按階段延遲 (以納秒為單位，示意值)
```
第0級延遲:
  Sum[0]  → 1 個XOR延遲 (t_XOR3: 3輸入異或)
  carry[1] → 1 個邏輯延遲 (t_carry)

第1級延遲 (需要等待carry[1]):
  Sum[1]  → t_carry + t_XOR3
  carry[2] → t_carry + t_carry

第2級延遲:
  Sum[2]  → 2×t_carry + t_XOR3
  carry[3] → 2×t_carry + t_carry

第3級延遲 (最壞情況):
  Sum[3]  → 3×t_carry + t_XOR3
  Cout    → 3×t_carry + t_carry
```

#### 時序複雜度
```
最壞情況總延遲 ≈ (n-1) × t_carry + t_XOR3
其中 n = 位元數 (本設計中 n=4)

對於4位加法器:
  總延遲 ≈ 3 × t_carry + t_XOR3  (約3~4級邏輯門延遲)
```

### 2. 關鍵時序路徑

```
最長路徑 (Longest Path / Critical Path):
  Cin → carry[1] → carry[2] → carry[3] → Cout
  
此路徑決定了加法器的最大工作頻率。
```

### 3. 時序特點

| 特徵 | 說明 |
|------|------|
| **優點** | 1. 邏輯簡單<br>2. 易於實現和理解<br>3. 面積小 (最少的邏輯門) |
| **缺點** | 1. 延遲與位元數線性相關 O(n)<br>2. 位元數越多，延遲越大<br>3. 不適合高速應用 |
| **適用場景** | 低速應用、教學演示、簡單計數器 |

## 設計對比

### 與其他加法器架構的比較

| 項目 | 行波進位加法器 (RCA) | 進位跳過加法器 (CSA) | 進位預測加法器 (CLA) |
|------|----------------------|----------------------|----------------------|
| **延遲** | O(n) | O(log n) | O(log n) |
| **面積** | 最小 | 中等 | 較大 |
| **功耗** | 低 | 中等 | 較高 |
| **複雜度** | 簡單 | 中等 | 複雜 |
| **設計難度** | 容易 | 中等 | 困難 |
| **適用位寬** | 4~8位 | 8~16位 | 16~32位 |
| **應用場景** | 教學、簡單電路 | 通用計算 | 高性能處理器 |

**本設計選擇 RCA 的原因:**
1. 邏輯簡潔，易於理解
2. 面積最小，適合學習
3. 功耗消耗較低
4. 對於4位加法，性能已足夠

## 驗證和測試

### 測試方法

#### 方法1: 邏輯驗證
```
驗證計劃:
1. 正常加法測試    (例: 3+5=8)
2. 進位溢位測試    (例: 15+1=16)
3. 邊界值測試      (例: 0+0, 15+15)
4. 進位輸入測試    (例: Cin=1的情況)
5. 所有進位傳播路徑測試
```

```
使用硬體模擬工具 (如 ModelSim、Vivado Simulator):

• 編寫仿真測試平台 (Testbench)

• 驗證結果正確性
```

#### 方法3: 綜合驗證
```
使用硬體綜合工具 (如 Xilinx ISE/Vivado):

• 檢查是否有報警或錯誤
• 驗證時序是否滿足要求
• 實際部署到晶片中驗證
```
